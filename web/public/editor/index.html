3 · Uložit

Jak dostat sprite do hry 1. Ulož PNG se jménem, které editor navrhne. 2. Soubory patří do web/public/assets/soldiers/ (vojáci), assets/props/ (rekvizity) nebo assets/locations/ (budovy). 3. Po přidání vojáků spustit npm run sprites (manifest + atlas). Stačí je poslat Claudovi, zařadí je. Chybějící směry hra zrcadlí (east ↔ west), role bez spritu se kreslí jako střelec.
